## 方法

真机编辑器要打开一个系列目录才能进入三栏界面，无头浏览器走不了原生文件对话框。故用一个临时入口 `harness.html` 在浏览器里塞入合成系列（6 张普通卡 + 1 张隐藏款），用同一套 React 组件渲染，再用 Edge 无头截图：

```
pnpm --filter @prismwright/desktop dev
msedge --headless=new --enable-unsafe-swiftshader --window-size=1440,900 \
  --screenshot=... "http://localhost:1420/harness.html?layout=focus&tab=layers"
```

`?layout=studio|focus|compact` 切布局，`?tab=design|layers|effects|export` 切页签。harness 用完即删，不提交。

截图存于 `docs/superpowers/notes/ui-qa-2026-11-28/`。

## 已核对

- **工作室**：顶栏 46 高浮层、左右栏圆角浮层与 8px 间隔、舞台直铺底色；左栏搜索/分组/卡片行/新建按钮；检查器头部 + 页签 + 分区卡。
- **专注**：左栏收起后舞台铺满，正/背面分段控件与视图胶囊仍可用。
- **紧凑**：左栏 5% 缩略图条，选中项绿环；`minSize` 允许压到 4%。
- **图层页**：添加层 2×2 按钮组、图层行 4px 内缩 + 圆角 + 深绿选中底、属性区字段行对齐。
- **设计页**：滑杆轨道 24 高、已滑过部分 `#2f6b55` 实心、手柄 8×16；数字框 44×24 与轨道同圆角；取色像素级核对（填充 `#2F6B55`、未填充 `#222222`、手柄 `#F1EFEB`）。
- **菜单/对话框**：菜单项 24 行高、圆角卡；确认框改用 Button。

## 发现并已修

1. 图层树选中行原先通栏铺色、无圆角 → 行加 `mx-1`、`rounded-control`、`h-row`。
2. 效果页分区卡标题沿用了「图层」，与页签重名 → 改为当前图层名。
3. 设置页两处 `max-w-[1100px]`、`text-[15px]` 等任意值 → 收入刻度（见守卫测试）。

## 未覆盖 / 待真机确认

- **画布内容**：无头环境拿不到可用的 WebGL 上下文，卡面本身没有渲染出来（截图里舞台为空白）。卡片、效果、光照观感需在 `pnpm dev` 的 Tauri 窗口里确认。
- **缩略图**：合成系列没有 `.previews`，卡片行显示编号回落块；真实系列的缩略图路径需在真机确认。
