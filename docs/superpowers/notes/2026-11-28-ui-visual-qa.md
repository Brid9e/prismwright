日期：2026-11-28
参照：`tools/ui-mockup`（已确认原型）
分支：`feat/ui-control-system`

## 方法

真机编辑器要打开一个系列目录才能进入三栏界面，无头浏览器走不了原生文件对话框。故用一个临时入口 `harness.html` 在浏览器里塞入合成系列（6 张普通卡 + 1 张隐藏款），用同一套 React 组件渲染，再用 Edge 无头截图：

```
pnpm --filter @prismwright/desktop dev
msedge --headless=new --enable-unsafe-swiftshader --window-size=1440,900 \
  --screenshot=... "http://localhost:1420/harness.html?layout=focus"
```

`?layout=studio|focus|compact` 切布局。harness 用完即删，不提交。

截图存于 `docs/superpowers/notes/ui-qa-2026-11-28/`。

## 已核对

- **顶栏**：与窗口上/左/右三边齐平、透明无容器背景；内容仍是三段栅格（品牌+菜单 / 标题 / 动作组）。
- **工作室**：左右栏圆角浮层与 8px 间隔、舞台直铺底色；左栏搜索/分组/卡片行/新建按钮；检查器头部 + 页签 + 分区卡。
- **专注**：左栏收起后舞台铺满，正/背面分段控件与视图胶囊仍可用。
- **紧凑**：左栏 5% 缩略图条，选中项绿环；`minSize` 允许压到 4%。
- **图层页**：添加层 2×2 按钮组、图层行 4px 内缩 + 圆角 + 深绿选中底、属性区字段行对齐。
- **设计页**：滑杆轨道 24 高、已滑过部分 `#2f6b55` 实心、手柄 8×16；数字框 44×24 与轨道同圆角；取色像素级核对（填充 `#2F6B55`、未填充 `#222222`、手柄 `#F1EFEB`）。
- **卡面**：修掉舞台高度塌陷后，WebGL 画布与卡面网格在合成系列里可见（软件渲染下观感不作为色彩依据）。

## 发现并已修

1. **卡牌不可见（阻断级）**：`PreviewPanel` 的舞台根节点只有 `flex-1`，而父级（分栏中心面板）不是 flex 容器，高度解析为内容高；画布是绝对定位、内容高为 0，于是整块画布尺寸为 0，卡片完全不渲染。改为 `h-full` 后恢复。
2. 顶栏与窗口上/左/右有 8px 分离且带容器背景 → 顶栏改为齐平透明，边距只留给其下的工作区。
3. 图层树选中行原先通栏铺色、无圆角 → 行加 `mx-1`、`rounded-control`、`h-row`。
4. 效果页分区卡标题沿用了「图层」，与页签重名 → 改为当前图层名。
5. 设置页两处 `max-w-[1100px]`、`text-[15px]` 等任意值 → 收入刻度（见守卫测试）。

## 未覆盖 / 待真机确认

- **画布观感**：无头环境用的是软件 GL，卡面在截图里呈现为一条斜向暗块（合成卡没有图片层，底色又接近棋盘格）。卡面、效果、光照的实际观感需在 `pnpm dev` 的 Tauri 窗口里确认。
- **缩略图**：合成系列没有 `.previews`，卡片行显示编号回落块；真实系列的缩略图路径需在真机确认。
- **1024×768**：未单独截图。顶栏右侧动作组在窄窗下可能挤（撤销/重做、保存、布局、导出、设置、窗口按钮），需真机看一眼是否换行或被裁。
- **设计页标签**：`宽高比（系列）` 在 60px 标签列下显示为「宽高比 (…」，属既定截断策略（悬停有 title）；若影响易读性，可把该面板标签列调到 72px。

## 结论

布局、控件刻度与三种模式与原型一致，测试全绿；卡牌不可见的根因已定位并修复，画布内观感待真机复核。
