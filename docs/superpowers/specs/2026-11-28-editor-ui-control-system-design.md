# 编辑器 UI 重置与控件系统设计

日期：2026-11-28
状态：设计方向已通过 HTML 原型（`tools/ui-mockup`）确认，等待实现
范围仓：`D:\Code\cardbara-editor`（桌面编辑器）

## 1. 背景

「卡面」已降级为纯图层（schema v9），检查器里不再有「正面 / 卡面效果 / 卡面蒙版」这层概念，但界面仍是围绕旧卡面模型长出来的：

- 三栏密排，左右栏与舞台共用一块底色，预览区被状态栏和底部信息条挤小；
- 控件各写各的：圆角 2/3/4px、蓝色强调色、细滑轨，与产品视觉（绿色、卡片内容）不一致；
- 参数散落在一条长滚动里（设计 → 图层树 → 图层详情），找东西靠滚。

本次重置的目标不是「换皮」，而是建立一套**能被后续所有界面复用的 token + 控件层**，并重排工作区。

## 2. 目标

1. 一套语义化设计 token（颜色、间距、高度、圆角、字级），组件不再写裸数值。
2. 一套基础控件（按钮、分段、滑杆、数字框、下拉、开关、颜色、分区卡、字段行、树行、标签、空态）。
3. 新的工作区结构：顶部工具条 + 左卡片库 + 中舞台 + 右检查器；舞台直铺背景，无状态栏。
4. 三种布局模式（工作室 / 专注 / 紧凑），可切换并记忆。
5. 检查器按「设计 / 图层 / 效果 / 导出」分页签，减少滚动查找。
6. 视觉方向：纯色、无装饰渐变、绿色为唯一强调色、厚圆角矩形滑轨。

## 3. 非目标

- 不改渲染器、着色器、schema 与任何卡片数据格式。
- 不更换 UI 库：继续 Tailwind + Radix，不引入 Element Plus / shadcn / Spline 的运行时。
- 不引入第三方字体（授权与体积原因），界面用系统 UI 字体，数值用等宽字体。
- 原型里出现但当前产品没有的能力**本次不实现**：舞台「光照」控制（需渲染器全局光源）、「对比」模式、顶栏全局搜索（避免与左栏搜索重复）。
- 不重做起始屏与设置页的信息架构，只做控件扫尾。

## 4. 方案

- **A（选定）**：在现有组件拆分上重写 token 与控件样式，重排三栏与顶栏；保留 Radix 行为与所有既有交互。
- B：只换配色与圆角，不动布局——解决不了预览过小与参数难找，且控件仍会各写各的。
- C：引入现成设计系统——授权、体积与视觉方向都不符，且会推翻现有可访问性实现。

## 5. 设计 token

### 5.1 颜色（语义 token，仍是主题覆盖的唯一接口）

| Token | 值 | 用途 |
| --- | --- | --- |
| `--color-surface-app` | `#080808` | 窗口底，舞台直接铺在它上面 |
| `--color-surface-panel` | `#151515` | 浮层面板（顶栏、左栏、右栏、对话框） |
| `--color-surface-elevated` | `#1c1c1c` | 行悬停、选中底、分段控件底 |
| `--color-surface-sunken` | `#101010` | 输入框、数字框、下拉底 |
| `--color-track` | `#222222` | 滑轨未滑过部分 |
| `--color-track-fill` | `#2f6b55` | 滑轨已滑过部分 |
| `--color-line` | `#2b2b2b` | 分隔线、面板内分区线 |
| `--color-line-soft` | `#232323` | 控件描边 |
| `--color-text` | `#f1efeb` | 主文字 |
| `--color-text-muted` | `#949494` | 标签、次级文字 |
| `--color-text-disabled` | `#6d6d6d` | 禁用、占位 |
| `--color-accent` | `#1fbf83` | 选中、开关、焦点环 |
| `--color-accent-hover` | `#35d79a` | 悬停 |
| `--color-accent-active` | `#0fa968` | 按下、主按钮底 |
| `--color-accent-soft` | `#113a2b` | 选中行底、开关开态底 |
| `--color-text-on-accent` | `#08140f` | 绿色底上的文字 |

约束：界面区域不使用渐变；卡片缩略图与卡面内容属于「内容」，可以有渐变。

### 5.2 间距（4pt 网格）

只允许 `4 / 8 / 12 / 16 / 24`（外加 1px 描边与 2px 微调）：

- 行内元素间距 `8`；字段行之间 `4`；分区内部 `12`；分区之间 `8`；面板内边距 `12`；窗口外边距 `8`。
- 标签列宽 `60px`（数字类）/ `72px`（文本类），同栏内保持一致。

### 5.3 高度

| 元素 | 高度 |
| --- | --- |
| 输入框 / 数字框 / 滑轨 / 分段项 | 24 |
| 下拉 / 颜色字段 / 按钮 | 28 |
| 字段行最小高度 | 32 |
| 检查器页签 | 32 |
| 顶栏 | 46 |
| 面板标题 | 40 |

### 5.4 圆角

| 元素 | 圆角 |
| --- | --- |
| 小徽标 / 色块 / 滑杆手柄 | 3 |
| **所有紧凑控件**（输入、数字、滑轨与填充、颜色、按钮） | **5** |
| 分区卡（检查器里的分组） | 8 |
| 浮层面板 / 对话框 | 12 |
| 左右两栏的外壳 | 14 |

### 5.5 字级

- 标签 11px / 500 / muted；数值与正文 12px；分区标题 12px / 600；检查器卡名 17px（衬线展示体）；顶栏品牌 13px。
- 数值（滑杆数字框、颜色值、坐标）统一等宽字体。

### 5.6 Tailwind 映射

`tailwind.config.ts` 直接暴露语义刻度，组件里只写语义类：

- 颜色：`bg-app` `bg-panel` `bg-elevated` `bg-sunken` `bg-track` `bg-accent` `text-foreground` `text-muted` `border-line` `border-line-soft` …
- 高度：`h-control`（24）`h-button`（28）`h-row`（32）`h-topbar`（46）
- 圆角：`rounded-chip`（3）`rounded-control`（5）`rounded-card`（8）`rounded-panel`（12）`rounded-sidepanel`（14）
- 字级：`text-label`（11）`text-body`（12）`text-title`（13）

禁止在 `src/ui` 与 `src/features` 里写 `rounded-[…]`、`h-[…]`、`gap-[…]`、`text-[…px]` 这类任意值；由守卫测试兜底（见 §10）。

## 6. 控件规范

状态矩阵（所有可交互控件一致）：

| 状态 | 表现 |
| --- | --- |
| 默认 | 中性灰描边 / 透明底 |
| 悬停 | 描边提亮到 `--color-line`，底变 `--color-surface-elevated` |
| 聚焦 | 1px `--color-accent` 描边 + 外 2px `ring-accent/25`；键盘可见，鼠标点击不常驻 |
| 按下 | 底 `--color-accent-soft`，文字 `--color-accent` |
| 禁用 | 40% 不透明度，`cursor-not-allowed` |
| 选中 | 绿色描边 + 深绿底 + 绿色文字 |

### 6.1 滑杆（重点）

- 轨道：高 24、圆角 5、底 `--color-track`、描边 `--color-line-soft`、内阴影 `inset 0 1px 2px rgb(0 0 0 / .35)`。
- 已滑过部分：同高、同圆角，实心 `--color-track-fill`。**必须与未滑过部分明显区分**。
- 手柄：8 × 16、圆角 3、近白 `#f4f1eb`，投影 `0 1px 4px rgb(0 0 0 / .45)`；聚焦时加 2px 绿色环。
- 数字框：43 × 24、圆角 5、等宽 10–11px、右对齐；与轨道同高、同圆角。
- 一行布局：标签（左）— 轨道（撑满）— 数字框（右）— 可选复位图标。
- 拖动期间持续 `onChange`；`onCommit` 语义不变。

### 6.2 其他控件

- 按钮：28 高，圆角 5；主按钮绿底深字，次按钮透明底 + `--color-line-soft` 描边，危险按钮红字。
- 分段控件：容器 28 高、圆角 5、`--color-surface-elevated` 底加 1px 描边；选中项底 `--color-surface-panel`、文字主色、轻微投影。
- 开关：30 × 17，关闭态中性；开态 `--color-accent-soft` 底 + 白色圆钮。
- 颜色字段：28 高；色块 15 × 15 圆角 3；右侧拾色图标。
- 下拉：28 高，圆角 5，右侧 chevron；菜单面板圆角 8、`--color-surface-panel`、投影。
- 分区卡：圆角 8、1px `--color-line` 描边、`--color-surface-elevated/40` 底；标题行 32 高，可折叠。
- 树行：高 30、圆角 5；选中态左侧 2px 绿条 + `--color-accent-soft` 底。
- 标签（稀有度）：圆角 3、9px、色底 15% 透明。

## 7. 布局与信息架构

### 7.1 工作区

```
┌──────────────────────────────────────────────────────────┐
│ 顶栏（46）：品牌/菜单 · 系列名 · (拖拽区) · 撤销/重做     │
│             · 保存状态 · 布局切换 · 导出 · 窗口控件       │
├───────────┬──────────────────────────────┬───────────────┤
│ 卡片库    │ 舞台（透明，直铺窗口底）      │ 检查器        │
│ 236       │  工具栏：正面/背面 · 预览/绘画 │ 348           │
│ 搜索      │  画布                         │ 标题+页签      │
│ 全部/隐藏 │  …                            │ 设计/图层/效果 │
│ /卡背     │  底部悬浮缩放胶囊              │ /导出         │
│ 卡片行    │                               │               │
│ 新建卡片  │                               │               │
└───────────┴──────────────────────────────┴───────────────┘
```

- **顶栏与窗口上/左/右三边齐平**：不铺容器背景、不留圆角与外边距（2026-11-28 修订：原本打算与面板一样浮在 8px 留白上，实机观感「在最顶端分离」，改回通栏透明）。
- 工作区（顶栏以下）外边距 8、面板之间 8；面板是浮在 `--color-surface-app` 上的圆角块。
- 舞台无背景容器、无状态栏、无底部胶片条。保存状态移到顶栏；保存失败时顶栏红点可点开错误详情。

### 7.2 布局模式

`uiStore.layout: "studio" | "focus" | "compact"`，持久化：

- **工作室**：236 / 1fr / 348。
- **专注**：0（左栏收起）/ 1fr / 348。
- **紧凑**：64（只留缩略图条）/ 1fr / 300。

切换按钮在顶栏右侧；左右栏仍可用分栏拖拽，拖拽结果覆盖当前模式的列宽并持久化。

### 7.3 检查器

- 头部：卡名 + 稀有度标签 + 副行（编号 · 系列）+ 「⋯」菜单。
- 页签：设计 / 图层 / 效果 / 导出。
  - 设计：身份（昵称、编号、稀有度、系列宽高比）、画布（底色、圆角、表面）。
  - 图层：添加层按钮组（底图/图片/文字/分组）+ 图层树 + 选中层属性（填充/位置/缩放/旋转/法线/混合与蒙版）。
  - 效果：选中层的效果栈（按相位/颜色/蒙版/内容分组）+ 选中效果参数。
  - 导出：单卡 PNG / GIF / WebM 与尺寸、背景、范围。
- 背面沿用同一套页签；「删除卡背」放在设计页签底部。

### 7.4 左栏卡片库

- 搜索框过滤卡片名与编号；分段筛选「全部 / 隐藏款 / 卡背」；卡背即系列的背面预览项。
- 卡片行：缩略图 30 × 42（有预览 PNG 时显示，否则稀有度色块）、昵称、编号、稀有度标签。
- 底部「＋ 新建卡片」常驻。

## 8. 与原型的功能取舍

| 原型元素 | 决定 |
| --- | --- |
| 顶栏全局搜索 | 不做；搜索只留在卡片库，避免两个入口语义重叠 |
| 舞台「光照」 | 不做；需渲染器全局光源，属非目标 |
| 「对比」页签 | 不做；当前没有对照图来源 |
| 视图控制胶囊的播放键 | 复用「预览 / 暂停动画」的既有能力 |
| 检查器「⋯」 | 复用现有上下文菜单动作 |
| 卡片缩略图 | 用后台已生成的 `.previews/<id>.png`，读字节转 object URL 并缓存；缺失时回落稀有度色块 |

## 9. 交互与状态

- 撤销 / 重做：顶栏图标，禁用态按历史栈自动置灰。
- 保存状态：`已保存`（绿点）/ `保存中` / `有改动` / `保存失败`（红点 + 可展开错误）。
- 布局模式与分栏宽度写入 `uiStore` 持久化；首次启动为工作室。
- 所有控件保留键盘可达：Tab 顺序 = 视觉顺序；滑杆支持方向键；分段控件用 roving tabindex。
- 空态统一用「图标 + 一行说明」，不使用大段占位文字。
- Toast 只在保存失败、导出完成、文件缺失这类异步结果出现，2.5s 自动消失。

## 10. 迁移与验收

- 迁移顺序：token → 基础控件 → 结构控件 → 顶栏 → 左栏 → 舞台 → 检查器 → 布局模式 → 其余页面 → 守卫测试。
- 每个阶段结束跑 `pnpm --filter @prismwright/desktop test`、`typecheck`、`build`。
- 守卫测试：扫描 `src/ui` 与 `src/features` 的 `*.tsx`，命中任意值写法即失败，白名单只允许数据驱动的内联尺寸（如缩略图宽高比）。
- 视觉验收：在 1440×900、1280×800、1024×768 三个尺寸下，对三种布局各截一张图，与 `tools/ui-mockup` 对照；重点检查滑轨填充/手柄、控件圆角一致、间距节奏、面板层级。
- 无功能回退：现有测试全绿；手动过一遍新建卡、加图层、拖动滑杆、撤销、导出、切换卡背。

## 11. 留给实现者的判断

- 面板折叠与整栏收起的旧交互（`uiStore.folded` / `collapsed`）保留语义，但视觉合并到新页签体系中：折叠箭头仍由面板头提供。
- 主题（`themes/builtin/github-dark.json`）需同步新 token；未覆盖的 token 自动回落默认深色。
- 缩略图缓存失效以 `.previews/manifest.json` 的哈希为准；读不到就回落色块，不阻塞列表。
