# Prismwright UI 原型

静态 HTML 原型，用来确认新版编辑器的工作区布局、信息架构和控件风格。**尚未接入真实应用**。

打开 `index.html` 即可；右上角可在三种布局间切换：

- **工作室**：左侧卡片库 + 中间舞台 + 右侧检查器（默认）
- **专注**：收起卡片库，放大预览，保留检查器
- **紧凑**：左侧只剩卡片缩略图，适合窄窗口

`?layout=focus` / `?layout=compact` 可直接打开对应布局；`?components=1` 打开控件总览。

截图：`studio.png` / `focus.png` / `compact.png` / `components.png`。

## 信息架构

- **顶部**：系列、全局搜索、撤销/重做、保存状态、布局切换、导出
- **左侧 · 卡片库**：全部 / 隐藏款 / 卡背；卡片缩略图、昵称、稀有度；新建卡片
- **中间 · 舞台**：画布直接铺在应用背景上，不套背景容器；正面/背面、预览/绘画/对比、缩放、光照；底部只有悬浮视图控制胶囊
- **右侧 · 检查器**：设计 / 图层 / 效果 / 导出
  - 设计：身份、画布底色、圆角、表面（标准/玻璃）、系列宽高比
  - 图层：底图 / 图片 / 文字 / 分组；图层树；选中图层的填充、位置、缩放、旋转、法线、混合与蒙版
  - 效果：按「相位 / 颜色 / 蒙版 / 内容」分组的图层效果栈；选中效果参数
  - 导出：PNG / GIF / WebM、尺寸、背景、范围

## 设计方向

- 参考 Spline 的 3D 编辑器质感：深色纯色视口、悬浮面板、白色主按钮、厚圆角矩形滑轨、紧凑数字框、顶部工具条、底部视图控制胶囊
- 界面不使用装饰性渐变；卡面预览里的渐变只属于示例卡面内容
- 示例卡面也改为品牌绿/青，不再用紫色；列表缩略图保留少量变化作为内容区分
- 绿色是唯一强调色（选中、开关、滑杆）；其余全部中性灰阶；卡面内容可保留自己的画面
- 字体：Instrument Serif 只用于卡名/品牌，界面用 Spline Sans，数值用 Spline Sans Mono
- 控件：分段控件、一行布局的厚圆角矩形滑轨（标签在左、数值在右；已滑过部分实心填充，未滑过部分为中性灰轨道）、颜色字段、开关、页签、标签、空状态、toast、tooltip
- 面板用半透明分组与细边框；检查器里的每个分组是一张圆角暗色卡，控制密度靠近 Spline
- 图层优先：底图只是最底层 image 图层，检查器默认打开「图层」
- 中间视口与窗口背景连成一片，左右面板与顶部工具条悬浮在上面

## 色板

| 用途 | Token | 值 |
| --- | --- | --- |
| 应用底 | `--ink` | `#0b0b0b` |
| 面板 | `--panel` | `#121212` |
| 顶栏/浮层 | `--panel-2` | `#141414` |
| 控件底 | `--control` | `#1c1c1c` |
| 分割线 | `--line` / `--line-soft` | `#2b2b2b` / `#232323` |
| 主文字 | `--text` | `#f1efeb` |
| 次级文字 | `--text-2` | `#cbc8c1` |
| 弱文字 | `--muted` | `#949494` |
| 强调 | `--accent` | `#1fbf83` |
| 危险 | `--danger` | `#e66a6a` |
| 稀有度 | `--rare` / `--epic` / `--legend` | `#78a8ff` / `#b18cff` / `#e7b764` |

强调色只用于选中、开关、滑杆和主操作；界面不铺渐变。
